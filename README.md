# Khmer Horror: Soul of the Forest
# Godot 4 prototype for a Khmer horror survival game.
#
# This project is designed as a mobile-friendly Godot foundation that includes:
# - Khmer and English language support
# - Main menu, settings, and information screens
# - 3D gameplay loop with player movement and ghost encounters
# - Inventory and dialogue system
# - Multiplayer-ready lobby structure and network placeholders
#
# Open this folder in Godot 4.x and press Play.
# For Android export: use Godot's Android export templates and APK build flow.
#

## Features included
- Khmer UI and English fallback
- Intro screen and gameplay HUD
- Horror atmosphere with jump-scare style ghost spawns
- Inventory and item collection flow
- Dialogue system using tr() and localization keys
- Multiplayer lobby placeholders for 2–8 players
- Offline mode placeholder for single-player play

## How to run
1. Install Godot 4.x
2. Open the project folder
3. Press F5 or the Run button

## Android / APK
- Use Godot's Export > Android menu
- Adjust package ID and keystore for release APK
- This project is made for APK packaging, not Play Store release

## Notes
This is a playable prototype foundation based on your requirements. A full 'AAA' horror game with all story scenes, voice acting, assets, and complete online networking would require a larger production pipeline and art/audio resources.
